Role-based Access control
Check the current user's security roles via the user table's security roles association. Two roles are relevant:
-"Order Admin" - full access
-"Order User" - restricted to their own orders
Branch the UI based on role:
If user has "Order Admin" role:
-Sidebar shows: catalog, My Orders, All Orders, Reports
-"All Orders" Page: table of every Order across all users
-Same columns as My Orders + "Ordered by" Column
-Filters: by Status, by Assigned To, by Date range
-Admin can edit Order Status and Assigned To inline (or via row action)
-"Reports" page: simple dashboard with:
-Total orders by Status (bar chart)
-Orders by Category (pie chart)
-Orders over time (line chart, last 30 days)
-Top 5 most-ordered items
-Admin can also create/edit/deactivate Catalog Items from the Catalog page (show "Manage" toggle)
If user has "Order User" role (or only Order user);
-Sidebar shows: Catalog, My Orders only
-Catalog is read-only browsing + Ordering
-My Orders shows only orders where Ordered By = current user
-No access to All Orders or Reports routes (redirect to Catlog if attempted)
If user has Neither role: 
-Show a friendly "Access Denied - Please contact your administrator" screen
